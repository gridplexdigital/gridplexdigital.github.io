The network effect

Some services become more useful as more people use them. This can create rapid growth and concentration, but network size alone does not guarantee trust or quality.

⚡ 2-Minute Field Note 📖 Looking for the full study? Read the 12-minute deep dive with book quotes →

The idea

Some services become more useful as more people use them. This can create rapid growth and concentration, but network size alone does not guarantee trust or quality. Treat this as a lens for examining a situation, not as a universal explanation. Context matters: ask what evidence supports the interpretation, what it leaves out and when the idea might not apply.

Put it to use

When evaluating a platform, distinguish user growth from durable value, switching costs and governance.
